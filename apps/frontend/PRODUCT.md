## Platform

web

## Users

IMS employees: Super Admin, Logistics Manager, Dispatch Executive, Warehouse Staff and Viewer/Auditor. Daily desktop planning and tablet/mobile warehouse work.

## Product Purpose

Execute payment-aware educational material logistics while retaining familiar Excel workflows. Improve employee coordination and visibility into exceptions.

## Operating Context

Admissions supplies enrolments; Finance supplies cleared milestones. Logistics plans kits, stock movement, couriers, returns and printing. Employees import workbooks, review issues, compare distributions and work from dense operational grids.

## Capabilities and Constraints

Next.js, Fastify, TypeScript, PostgreSQL and Prisma. No student login, payment collection or upstream financial edits. The user explicitly requests both workbook analysis and a live Excel-style operations grid, employee profile/status, communication and credentials for other roles. Workbook analysis must remain separate from authoritative ingestion.

## Brand Commitments

IMS Learning Resources. Latest user direction: luxury editorial / wabi-sabi typography and calm materials, with smooth interactions. Preserve real product language, practical data controls and employee permissions.

## Product Principles

Expose exceptions before action. Keep source ownership explicit. Every material movement is transactional and audited. Real records drive every chart. Employee tools work with keyboard and mobile devices.

## Accessibility & Inclusion

Labelled controls, visible focus, keyboard dialog dismissal, reduced motion, responsive tables and readable numerical comparisons. WCAG AA target requires release validation.
